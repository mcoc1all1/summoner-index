Masteries / Recoil / Liquid Courage / Double Edge
HIGH-OFFENSE BUILD

Recoil / Liquid Courage / Double Edge

A high-damage setup built around Recoil, Liquid Courage and Double Edge. It can be excellent for compatible rosters but is not a universal upgrade.

Best for

Champions that tolerate or benefit from Bleed/PoisonFast farmingRoster-specific high-damage setups

Build priorities

  1. Use the minimum Recoil investment required to access the branch, then commit to Liquid Courage / Double Edge only if your roster can handle the self-debuffs.

  2. Willpower becomes a major support mastery because it can recover health while debuffs are active; Recovery can further improve sustain.

  3. Coagulate can reduce the impact of the opening Bleed from Double Edge for champions that are not fully Bleed immune.

  4. Prefer champions that are Bleed/Poison immune, resistant, shrug the effects, or otherwise turn the self-debuffs into an advantage.

What to watch

  • Recoil damages you after Special Attacks, which can be a serious problem for champions whose rotations depend on repeated Specials.

  • Liquid Courage and Double Edge apply self-damaging debuffs; roster compatibility matters more than the headline attack increase.

  • Kabam changed Liquid Courage and Double Edge attacker damage scaling in 2024 so the self-damage uses the lesser of modified or base Health. That helps boosted attackers but does not remove the tradeoff.

  • This setup is usually less attractive for long-form content and many Battlegrounds decks where health preservation matters.
