SOURCED FIGHT GUIDE

Learn the fight loop

Guide reviewed 2026-10-30 · Not gameplay-tested in the current build

A short preparation aid. Read the full in-game boss abilities before entry; this is not an exhaustive mechanics transcript.

Start here — read the Signature Ability

Act 9.4.6 contains three different Carina versions. Identify the Signature Ability before choosing a guide: Mutant-Mystic Vulnerability, Science-Tech Vulnerability or Skill-Cosmic Vulnerability. The vulnerability pair names the attacker classes the fight is designed to favor; it is not the class pair Carina is emulating.

Shared rule — build Chrono Corruption

Every version has a different route mechanic that inflicts Chrono Corruption on Carina. Fight A uses Encroaching ISO Infection, Fight B uses Corrupted ISO Blast, and Fight C uses Corrupted ISO Traps. Use the dedicated variant page for the exact input sequence.

Shared rule — build Elder’s Resistance

Elder’s Resistance is a Cross-Fight attacker resource earned through variant-specific RPG interactions. It helps the attacker recover damage taken from Carina’s Special Attack pressure, but each variant awards it differently.

Fight A

Mutant-Mystic Vulnerability. Carina emulates Skill/Cosmic mechanics. Progress Chrono Corruption through Encroaching ISO Infection and plan around later Special Lock / Striker Lock timing.

Fight B

Science-Tech Vulnerability. Carina is treated as Mutant/Mystic. Progress Chrono Corruption by reflecting Corrupted ISO Blast and manage Prowess plus the second-half Root sequence.

Fight C

Skill-Cosmic Vulnerability. Carina emulates Science/Tech mechanics. Progress Chrono Corruption through Corrupted ISO Traps and respect Inexorable before attempting the required knockback.

Special fourth path — three fights plus finale behavior

Full exploration includes the three variants and a special path that presents them together. Community reports describe a story sequence near the end in which Carina can refill Health before the intended finish. Keep that finale separate from the normal finish conditions of any one variant.

Common mistakes

  • Using the emulated class pair as the page name and therefore opening the wrong variant guide.

  • Assuming the three mechanics are phases of one fight rather than three separate Carina versions.

  • Applying the special fourth-path finale behavior to an ordinary individual variant.

Team selection and preparation

Choose the dedicated page by the exact Signature Ability shown in-game. Do not select only from a video title or shorthand such as 'Mystic Carina' because community sources sometimes name the emulated classes and sometimes name the vulnerability pair.

Attacker profile

These are useful traits, not a claim that one Champion is mandatory.

  • First choose the correct variant page; each version rewards a different class pair and uses a different Chrono Corruption mechanic.

  • Bring an attacker whose normal rotation still leaves room to execute the variant mechanic instead of maximizing raw damage only.

  • Treat Elder’s Resistance as sustain support and Chrono Corruption as the progression mechanic.

Before entering

  • Read the Signature Ability and the route mechanic before selecting a Champion.

  • Open the dedicated variant guide rather than trying to follow all three mechanic sets on one page.

  • If you are on the special fourth path, keep the reported finale behavior separate from the normal individual-fight finish.

When the fight goes wrong

Two guides call the same Carina by different class pairs

Check whether the source is naming Carina’s emulated classes or the Signature Ability vulnerability pair. Summoner Index names the dedicated pages by the Signature Ability shown in-game.

The mechanic on my screen does not match this page

Return to the overview and open the page whose Signature Ability and route mechanic match your node panel.

Carina refills Health on the special path

That behavior belongs to the combined story finale and has had inconsistent player reports. Follow the on-screen dialogue and do not assume an ordinary variant finishing rotation applies.
