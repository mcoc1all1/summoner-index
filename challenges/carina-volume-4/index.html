Plan the correct quest

The Ordeal is the enhanced Gauntlet. Abyss accepts any completed path through the Nameless Collector. True Olympian is one five-champion gauntlet containing the original Epoch fights and Ares; it does not use the original class gates or path-wide nodes.

These are community-sourced planners, not exhaustive node transcripts or independent gameplay tests. Abyss Heroes covers selected fights only; Abyss Villains includes a proposed team plan rather than a documented completed run.
