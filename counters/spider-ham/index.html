Fight plan

Set up Coldsnap and Trick Arrow pressure, keep True Accuracy available for Evade control, and bait Specials instead of feeding Porker Poppers with careless Special Attack use.

Check before choosing

  • Keep an anti-Evade effect active before committing to long combos.
